# Student Management System

A small Python console project that demonstrates storing student details in
`Student` objects and displaying each student's information and result.

## Features

- Store a student's name, class, marks, section, and registration number.
- Calculate a grade, GPA, and remark from the student's marks.
- Print one student's information and result.
- Display the students currently stored in a `Classroom`.

## Run

Requires Python 3.

```bash
python studentmanagementsystem.py
```

The current program runs with two sample students defined in the source code.
It does not yet support adding or editing records through user input, or saving
records to a file.
